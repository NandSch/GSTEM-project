# Archief van sessies

Elke afgeronde sessie staat in een eigen map `JJJJ-MM-DD_UUMM_<slug>/` met:

- `chat.md` — het volledige transcript van die sessie
- `meta.md` — datum, sessie-id, aantal berichten en geregistreerde onderwerpen
- `onderwerpen.md` — momentopname van het onderwerpenregister (indien aanwezig)

De huidige sessie staat in `../chat.md`.
